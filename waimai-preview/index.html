外卖配送系统

外卖点餐与配送管理平台：顾客、商家、骑手、管理员四种角色数据联动，覆盖下单、接单、配送、送达、评价、回复的完整业务流程。

真实运行截图 · 1280×860

登录页 · 四种身份选择顾客 / 商家 / 骑手 / 管理员身份卡片，支持注册与找回密码（验证码演示）
顾客端 · 点餐浏览商家 → 查看菜品 → 加入购物车；「我的地址」可保存多个收货地址并设默认
商家端 · 菜品与订单菜品管理支持实拍图上传，无图自动用 emoji 占位；接单 / 拒单一键操作，可回复评价
骑手端 · 抢单大厅实时查看待配送订单，抢单后开始配送，送达一键标记；附个人收入统计
管理员端 · 可视化看板近 7 天订单量与营收走势、订单状态分布饼图、商家营收排行、用户管理

四种角色

顾客

浏览下单、地址簿管理、订单跟踪、环保餐具选择、评价打分

商家

接单拒单、菜品上下架、实拍图上传、评价回复、营收统计

骑手

抢单大厅、配送状态流转、送达确认、个人收入统计

管理员

全平台数据看板、用户管理、商家运营情况一览

本地运行

需要 Python 3.10+，默认使用 SQLite，无需另装数据库

# 1. 进入项目目录 cd waimai-delivery-system # 2. 初始化数据库（首次运行；示例账号密码统一为 123456） python init_db.py # 3. 启动服务 python app.py # 打开 http://127.0.0.1:5000 # 示例账号：alice / xiaomei / qiang / lina（顾客）· shop_zha（商家）· bob / zhou（骑手）· admin（管理员）

跑通后可执行 python tests/smoke_test.py，77 项接口冒烟测试自动验证全流程。
