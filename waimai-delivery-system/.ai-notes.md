## 项目一句话总结

`waimai-delivery-system` 是把两份大二下《管理信息系统》作业合并成的能跑的外卖后台：

- **业务表结构** 来自 `final project qwq/`（Users / Merchants / Dishes / Orders / Order_Details / Deliveries / Comments 共 7 张表，原本只接 SQLite + FastAPI，只实现了登录/注册）
- **前台 + Flask 框架** 来自 `final project minimal working example/`（原本要装 MySQL 才能跑）

合并版默认走 SQLite，零配置。MySQL 走 `.env` 一行切换。

## 关键设计点

1. **数据库路径不写死**：靠 `.env` 文件 + 环境变量；git 已经 ignore 掉 `.env` 和 `*.db`
2. **双后端适配层**：`app.py` 里有个 `DB` 类，把 sqlite3 和 pymysql 抽象成统一接口（占位符自动切换 `?` / `%s`）
3. **示例数据密码统一是 `123456`**（见 `init_db.py` 的 `SAMPLE_PASSWORD`），避免有人拿到代码登录不了
4. **`publish_to_github.ps1`** 是给用户后续维护用的辅助脚本，不是项目运行的一部分

## 已知坑（下次再改时记得）

- `werkzeug.security` 的 pbkdf2 哈希会因为内部 salt 不同导致两次哈希不一样——所以示例数据先 INSERT 占位密码，再用 `init_db.py` 覆盖成真实哈希
- SQLite 不支持 `AUTO_INCREMENT` 而是 `AUTOINCREMENT`，注意两套 schema 写法不同
- `app.py` 里 row 转 dict 的 `_to_dicts()` 是为了兼容 sqlite3.Row 和 pymysql DictCursor——别简化掉
